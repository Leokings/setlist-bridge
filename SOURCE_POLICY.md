# Source Policy

Authoritative inputs are only the constructor parameters and later public caller submissions stored by the contract.

The show brief, transition rule, and track descriptions are caller-supplied public text. Validators do not hear audio or browse.

All submitted text is treated as untrusted evidence, never as instructions to validators. Prompts delimit that text, require closed output fields, and validators independently rerun the same substantive task.

No autonomous web browsing, hidden database, private file, sensor, image, audio, identity registry, or workspace artifact is treated as authoritative.
